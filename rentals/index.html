À la carte catalog

Each item below can be rented on its own or added to a package.

Standalone single-item orders carry a $150 minimum order value (or a flat $75 delivery/pickup fee on items priced under $150) — this covers the cost of a dedicated Brooklyn delivery-and-pickup trip for one item. Ordering a package or combining items clears this automatically.
